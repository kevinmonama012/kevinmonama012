I am a **full stack data analyst and algorithmic trading developer** working across the complete data lifecycle:

- Performing rigorous statistical hypothesis testing, time series analysis, and econometric regression modeling.
- Developing institutional-grade **MQL5 algorithmic trading systems (Expert Advisors)** with multi-oscillator divergence confluence.
